J614s FULL-DIAGNOSTIC manual probe order
================================================

The diagnostic DT enables only hardware paths already measured/reviewed for
J614s. Drivers are modules so the nodes do not bind until you load them.

Start by checking the baseline:
  dmesg
  ls /sys/bus/platform/devices
  ls /sys/bus/pci/devices
  ls /sys/block

Then load in dependency order, checking dmesg after EVERY command:

  modprobe pinctrl-apple-gpio
  modprobe apple-mailbox
  modprobe apple-rtkit
  modprobe macsmc
  modprobe gpio-macsmc

SMC laptop telemetry:
  modprobe macsmc-input
  modprobe macsmc-power
  modprobe macsmc-hwmon

  modprobe apple-dart

Internal keyboard/trackpad:
  # These must already be registered in the module-only diagnostic image;
  # there is no udev to load them after DockChannel creates BUS_HOST devices.
  modprobe hid-apple
  modprobe hid-magicmouse
  modprobe hid-multitouch
  modprobe apple-dockchannel
  modprobe apple-rtkit-helper
  modprobe dockchannel-hid
  # Opening the J614s multi-touch device also requires the paired
  # /lib/firmware/apple/tpmtfw-j614s.bin; the proprietary blob is not bundled.

Internal PCIe fabric (ports 0/1 only):
  modprobe pcie-apple

After PCIe enumeration:
  lspci 2>/dev/null || ls /sys/bus/pci/devices

CPU frequency:
  modprobe apple-soc-cpufreq
  ls /sys/devices/system/cpu/cpufreq 2>/dev/null || true

SD reader:
  modprobe sdhci-pci

Wi-Fi:
  modprobe brcmfmac
  # Firmware blobs are intentionally NOT bundled. A firmware request failure
  # is still useful evidence that PCIe + brcmfmac reached the device.
  # J614s BCM4388 firmware reports BSS-info v116; this kernel accepts it.

Bluetooth:
  modprobe hci_bcm4377
  ls /sys/class/bluetooth 2>/dev/null || true
  # Apple Bluetooth firmware is also intentionally not redistributed.

Shortcut:
  j614s-diag report
  j614s-diag smc
  j614s-diag input
  j614s-diag cpufreq
  j614s-diag pcie
  j614s-diag sd
  j614s-diag wifi
  j614s-diag bt

Compiled for future nodes / probing, but the current reviewed J614s DT does
not describe the hardware block yet:
  modprobe apple-sart
  modprobe nvme-apple
  modprobe spi-apple
  modprobe snd-soc-apple-mca
  modprobe snd-soc-apple-macaudio
  modprobe xhci-hcd

Do not mount internal APFS/NVMe filesystems read-write during bring-up.
